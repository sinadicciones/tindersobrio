# PlanSobrio — Dating y Conexiones Sobrias 🇨🇱

App chilena para conocer personas que viven sin alcohol ni drogas: **apoyo, amistad, grupos y amor** — con el plan sobrio incluido.

Proyecto de [SinAdicciones](https://sinadicciones.org).

## Estado

📋 **Fase de planificación.** El plan completo de producto, arquitectura y roadmap está en [PLAN.md](./PLAN.md).

## Resumen

- **Problema**: al dejar el consumo, reconstruir la vida social es lo más difícil. En las apps de citas tradicionales todo gira en torno al alcohol.
- **Solución**: una app donde la sobriedad es el punto de partida y cada match viene con un plan sin alcohol propuesto (café, caminata, museo…).
- **Mecánica central**: match por plan — "¿harías este plan con esta persona?" en vez de solo like.
- **4 modos**: 🤝 Apoyo · 🙂 Amistad · 👥 Grupos · ❤️ Amor.

## Stack (planificado)

- **Mobile**: React Native + Expo
- **Backend**: Supabase (PostgreSQL, Auth, Realtime, Edge Functions)
- **Admin**: Next.js
- **Contenido/SEO**: sinadicciones.org

Ver [PLAN.md](./PLAN.md) para el detalle completo: modelo de datos, algoritmo de matching, seguridad, moderación y roadmap de 12 semanas.
